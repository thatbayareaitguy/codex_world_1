# Manual QA Checklist

Record date, environment, tester, and evidence for each item. An unchecked item is not claimed as tested.

- [ ] Fresh installation and first migration
- [ ] Upgrade an existing pre-stabilization database
- [ ] Missing database and provider credentials
- [ ] Spotify connection and browser redirect
- [ ] Spotify reconnection after invalid authorization
- [ ] Followed-artist import and import rerun
- [ ] Manual artist creation, editing, and removal
- [ ] Exact and ambiguous MusicBrainz mapping
- [ ] Mock scan and repeated mock scan
- [ ] Optional real Spotify dry-run smoke test
- [ ] Feed search, date, provider, availability, and state filters
- [ ] Review confirmation, dismissal, and return to review
- [ ] Playlist preview, synchronization, and synchronization rerun
- [ ] Provider failure isolation and partial scan status
- [ ] Interrupted scan and stale-lock recovery
- [ ] Reddit disabled and approval-required states
- [ ] Reddit source add, pause, enable, and remove
- [ ] Backup, destructive restore confirmation, and restored data verification
- [ ] Spotify disconnect and token deletion
- [ ] Delete all application data
- [ ] Keyboard navigation and visible focus
- [ ] Mobile-width layout
- [ ] Empty, loading, success, disabled, and error states
